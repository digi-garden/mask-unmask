# MU-COMP-006 製品UI配色と正式ブランド表現の例外評価

## 規約と評価対象

- 正本：`digi-garden/brand-assets` 固定コミット `31bf40e921661c9c8e7b246434b349ad71c7c578`
- `guidelines/digi-garden-brand-guidelines.md` の正式ロゴ・配色は製品固有仕様で黙示的に上書きできない。
- `guidelines/digi-garden-standards-index-v1.0.md` 第5節は、例外について対象・理由・影響・代替措置を製品側に記録するよう規定。
- `guidelines/digi-garden-development-operations-guidelines-v1.0.md` 第7節は判断者と見直し時期も要求。

## 現行実装の事実

`tailwind.config.js` の製品UIトークンはダークテーマ（`bg #0f172a`、`surface #1e293b`、`primary #10b981`、`primaryHover #059669`）であり、正式ブランドの基本カラー（`#216B73`／`#F29A65`／`#FAFAF8`／`#153F44`）を画面全体に流用していない。

この差分は製品UIの配色に関するものであり、**正式シンボル、ワードマークの色、アスペクト比、余白、使用アセットを変更する許可ではない**。現行の提供元表示・ロゴ・faviconがブランド正式素材と一致するかは、別途実アセット照合を要する。

## 例外候補の評価（承認前）

| 項目 | 記録 |
|---|---|
| 対象 | Mask & Unmaskの機能UIに限定するダーク／emerald配色 |
| 理由 | 既存ユーザーの操作場所・意味を保ち、安全性ツールとして暗所でも識別しやすいUIを維持するため。改色による余分な回帰リスクを避ける |
| 影響 | ブランド基本配色との見た目の差異が残る。色コントラスト・非文字UI部品・色以外の識別は独立に確認が必要 |
| 代替措置 | 提供元表示・正式ロゴ等のブランド識別子は原則正式アセットを使用。対象テキストのコントラストと見出し階層はChromium E2Eで検査済みだが、全面的WCAG 2.2 AA適合を意味しない |
| 例外範囲 | 機能UIの背景・ボタン等の色トークンのみ。ロゴデザイン、広報素材、著作権表記、プライバシー安全要件は対象外 |
| 見直し時期 | 次回のUI再設計時、ブランドガイドライン変更時、またはアクセシビリティの不足が判明した時 |
| 判断者 | **NOT_RUN：製品責任者の承認記録が必要** |
| 最終状態 | **提案・未承認。MU-COMP-006の正式クローズは保留** |
