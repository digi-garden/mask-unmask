# X告知用デモ動画

Node.js依存関係をインストールした環境で、次の1コマンドを実行します。

```bash
npm run demo:video
```

アプリの本番ビルドとローカルプレビュー起動、Playwrightによる1280×720の操作録画、H.264 MP4への変換を自動で行います。FFmpegは`ffmpeg-static`の同梱バイナリを使うため、システムへの別途インストールは不要です。

生成先は`artifacts/mask-unmask-x-demo.mp4`です。`artifacts/`以下の生成物と一時ファイルはGit管理対象外です。

デモは固定データだけを使い、Geminiを含む外部サービスへのアクセスやログイン、API連携は行いません。期待する4件のタグと復元結果を録画中に検証し、一致しない場合はMP4を生成せず失敗します。

## 動画用フォント

録画時の日本語字形を生成環境によらず固定するため、Google Fonts公式リポジトリで配布されている可変フォント`Noto Sans JP`を`scripts/assets/fonts/NotoSansJP-wght.ttf`へ同梱しています。ライセンスはSIL Open Font License 1.1で、全文を同じディレクトリの`OFL.txt`へ収録しています。

動画生成スクリプトが録画ページ内だけへ`@font-face`と上書きスタイルを注入します。本番ビルドへフォントを含めず、通常表示のCSSにも影響を与えません。実行時の外部通信やOSインストール済みフォントは使用しません。
