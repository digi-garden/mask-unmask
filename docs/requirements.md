# 要件定義書：Mask & Unmask (MVP)

## 1. プロジェクト概要

* **製品名称：** Mask & Unmask
* **ドメイン：** `circle-note.com`
* **プロダクトコンセプト：** 「ChatGPTやClaudeに社内ログや文章を投げる前の必須ステップ」。入力テキストの外部送信ゼロ・ブラウザ内完結の完全ローカル処理で、機密情報を秒で『仮名化 ↔ 復元』するWeb書き捨てメモ。
* **ターゲットユーザー：**
  * エンジニア・個人開発者（本番ログ、ソースコード、APIキーの保護）
  * ブロガー・ライター・ビジネスパーソン（社内文書、個人情報、顧客データの保護）
* **コアバリュー（エッジ）：**
  * **データ外部送信ゼロ**：入力されたテキストや置換マップは一切外部に送信されず、すべての変換処理がユーザーのブラウザ内で完結するため、アプリケーション自身による外部送信に起因する漏えいリスクを抑える。
  * **決定的なルールベース置換**：AI推論を使用せず、定義済みのルール（正規表現等）に基づく決定的な変換を行う。ハルシネーションによる誤動作を防ぎ、自動検出された結果は置換マップ一覧から確認および個別削除などの編集が行える。
  * **双方向変換（復元）**：単なる黒塗りではなく、AIから返ってきた回答を一瞬で「元の本物データ」に戻せる。

| 項目 | 条件・採用技術 |
| :--- | :--- |

## 3. 機能要件 (MVPスコープ)

### 3.1. デバイス環境による機能制限
スマートフォン等の狭い画面（画面幅 768px 未満）では、画面サイズと操作性の制約から、以下の通り機能を制限します。
* **利用可能:** 自動検出による仮名化（Mask）、自動復元（Unmask）、テキストコピー、置換マップの一括クリア。
  * ※モバイルではカスタム単語登録およびインポート・エクスポートのUIのみ制限します。保持済み置換マップによる復元処理はPC・モバイルで共通（画面幅の変更で復元データが消失しないための共通エンジン化）とします。
* **利用不可（UI非表示/無効化）:** カスタム単語指定（サイドバー連携）、置換マップのエクスポート・インポート。

---

### 3.2. 機能1：仮名化（Mask）タブ
1. **テキスト入力機能**
   * 生の文章・ログ・コードをコピペ貼り付け可能な入力エリア。
2. **定型機密データの自動検出（決定的なパターンマッチ）**
   * 定義済みのルールに基づき自動で検出した文字列を、`[CN_CATEGORY_0001]` 等の固有タグ形式に仮名化する（ON/OFFトグル付き）。
   * **重複時の扱い:** 同じ値が複数回出現した場合は、同一のタグを割り当てる。
   * **優先順位:** 検出パターンの衝突を避けるため、以下のルールで適用する：
     * **最長マッチ優先:** 同じ開始位置から始まる複数のパターンがある場合、最も長い検出結果を採用する。
     * **カテゴリ優先順位:** 一部が重複・交差する場合、`APIKEY` ➔ `EMAIL` ➔ `PHONE` ➔ `IPV6` ➔ `IPV4` の順に優先適用する。すでに他カテゴリで仮名化された領域（文字列位置）は検出から除外する。
   * **冪等性:** 既に仮名化されたタグ（`[CN_..._...]` 形式）が存在する場合は、重ねて仮名化しない（二重仮名化の防止）。
   * **既存タグとの衝突防止:** 入力テキストに最初から `[CN_..._...]` 形式の文字列が含まれていた場合は置換をスキップし、ユーザーに警告を表示する。
   * **トグルOFF時:** 特定カテゴリの自動検出トグルをOFFにした場合、そのカテゴリの仮名化タグは解除（元のテキストに戻る）され、置換マップからも削除される。
3. **置換マップ管理・編集機能**
   * 検出・登録された置換マップ一覧を表示し、手動で個別に削除（除外）できる。個別削除された箇所は、即座に仮名化テキスト上で元の文字列に復元される。
   * **除外リストの適用期間:** 個別削除した元の値は「現在の入力内容に対する一時的な除外リスト」に登録され、入力テキストが変更されるまで再検出（再仮名化）を抑止する（入力テキストが変更された時点で除外リストはリセットされる）。
4. **カスタム単語指定（サイドバー連携 / PCのみ）**
   * ユーザーが入力テキスト内の単語を選択した際、選択された単語を登録パネル（サイドバー等）に自動転記（ロック）する。
   * ユーザーが別の場所をクリックしても転記された単語は保持され、追加ボタンを押すことで一括置換および置換マップへの登録が行われる。
5. **仮名化テキストの出力＆ワンタップコピー**
   * 仮名化されたテキストを表示し、コピーボタンでクリップボードへ保持。
   * **クリップボード失敗時の挙動:** Clipboard APIが非対応・権限拒否などで失敗した場合は、テキストを自動で全選択状態にし、「手動でコピー（Ctrl+C）してください」というエラーメッセージ/トーストを表示する。

### 3.3. 機能2：復元（Unmask）タブ
1. **AI回答テキストの入力**
   * ChatGPT等のAIから得た回答テキスト（`[CN_CATEGORY_0001]` などが含まれる文面）を貼り付けるエリア。
2. **自動アンマスク（復元）処理**
   * **置換バッティング対策:** タグの重複置換トラブル（部分一致など）を防ぐため、タグの文字列長が長い順（降順）に置換を処理する。
   * **表記揺れ制限:** データ破損を防ぐため、表記揺れ許容範囲を以下に限定する：
     * ASCIIの大文字・小文字を無視して一致判定。
     * 角括弧 `[` `]` とカテゴリ名、数字の間の空白のみを許容（例: `[ cn_custom _ 0001 ]` ➔ `[CN_CUSTOM_0001]`）。
     * タグ全体が完全一致した場合のみ復元（部分一致による意図しない通常テキストの破壊を防止）。
     * 曖昧な候補が複数存在する場合は自動復元を行わず、警告を表示。
3. **復元状況の明示**
   * 復元成功件数、および未復元のタグ件数・一覧を画面上に明示する。
4. **復元テキストの出力＆ワンタップコピー**
   * 元の単語に戻った完成テキストを出力し、コピー可能にする（コピー失敗時は手動コピーのフォールバックあり）。

### 3.4. 共通・補助機能
1. **置換マップの一括クリア（リセット）**
   * 仮名化・復元両タブの入力・出力エリア、および `sessionStorage` 上の置換マップを一括で消去し、初期状態に戻す（全デバイス共通）。
   * **破壊的操作の保護:** 実行時に「置換マップとテキストが完全に消去されます。この操作は取り消せません。よろしいですか？」という確認ダイアログを表示する。
   * 実行完了時はトーストで通知する。Undo（取り消し）は非サポートである旨を明記。
2. **置換マップのエクスポート・インポート（PC専用）**
   * **エクスポート:** 現在保持している置換マップ（仮名化タグと元の値のペア）を、JSON形式でローカルにダウンロード保存する機能。
     * ※セキュリティ警告: エクスポートボタン付近に「ダウンロードするファイルには元の機密情報がすべて含まれます。取り扱いに十分注意し、不要になったら速やかに削除してください」という警告を表示する。
   * **インポート:** 保存したJSONファイルを読み込み、置換マップを復元する機能。
     * **インポート仕様:**
       * 文字コード: UTF-8。最大ファイルサイズ: 500KB。最大件数: 1000件。
       * 重複の扱い（マージ衝突規則）:
         * **同一のタグで異なる original:** インポート側のタグを、既存マップと重複しない新しい連番に自動リナンバリングしてマージする。
         * **異なるタグで同じ original:** 既存のタグを優先し、インポート側のタグは統合して破棄する。
         * **同一のタグで異なる category:** タグ名の連番をリナンバリングして別タグとして登録する。
         * **マージ後の上限超過:** マージ結果が1000件を超える場合、インポートを中断し、超過エラーを表示する。
       * 異常値処理: 不正なタグ、未知のフィールド、壊れたJSONの場合はインポートを中断する。また、JSON Schemaの検証後、アプリケーション側でタグのプレフィックス（例: `[CN_EMAIL_0001]` なら `EMAIL`）を抽出し、`category` プロパティの値と一致しているかを検証し、不一致の場合はエラーとしてインポートを中断する。
       * 確認プレビュー: インポート前に、適用される置換ルールの一覧（タグ数、元の値のプレビュー）を確認ダイアログで表示し、ユーザーの合意を得る。
3. **容量制限への配慮**
   * `sessionStorage` の容量超過エラー（`QuotaExceededError`）をキャッチした場合、処理を中断して「ブラウザの保存領域が不足しています。不要なマップを削除するか、テキストをクリアしてください」という警告メッセージを表示する。

| カテゴリ | 検出ルール・形式（正規表現等の対象範囲） | 入力例 | 期待される仮名化結果 | 除外（非対象）例 |
| :--- | :--- | :--- | :--- | :--- |
| **APIKEY** | **OpenAI**: `sk-proj-[a-zA-Z0-9]{40,}`<br>**AWS ID**: `AKIA[0-9A-Z]{16}`<br>**GitHub**: `ghp_[a-zA-Z0-9]{36}` | `sk-proj-AbCdEfGhIjKlMnOpQrStUvWxYz0123456789aBcDeFgHiJ`<br>`AKIAIOSFODNN7EXAMPLE` | `[CN_APIKEY_0001]`<br>`[CN_APIKEY_0002]` | `sk-short-key`<br>`AKIA_TEST` |

## 5. 置換マップのJSONスキーマ定義
インポート・エクスポートされるJSONのスキーマです。

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "MaskUnmaskSubstitutionMap",
  "type": "object",
  "required": ["version", "createdAt", "mappings"],
  "additionalProperties": false,
  "properties": {
    "version": {
      "type": "string",
      "const": "1.0"
    },
    "createdAt": {
      "type": "string",
      "format": "date-time"
    },
    "mappings": {
      "type": "array",
      "maxItems": 1000,
      "items": {
        "type": "object",
        "required": ["tag", "original", "category"],
        "additionalProperties": false,
        "properties": {
          "tag": {
            "type": "string",
            "pattern": "^\\[CN_[A-Z0-9]+_\\d{4}\\]$"
          },
          "original": {
            "type": "string",
            "minLength": 1,
            "maxLength": 1000
          },
          "category": {
            "type": "string",
            "enum": ["APIKEY", "IPV4", "IPV6", "EMAIL", "PHONE", "CUSTOM"]
          }
        }
      }
    }
  }
}
```

## 7. 非機能要件

### 7.1. パフォーマンス目標
* **初期ロード時間:** キャッシュなしの初回訪問（コールドロード）時に、モバイル回線（Fast 3G）環境でFCP (First Contentful Paint) 1.5秒以下、ブロードバンド環境で0.5秒以下、LCP (Largest Contentful Paint) 2.0秒以下で画面が表示されること。
* **テキスト変換処理:** 100KB（約5万字）の入力テキストを対象に、標準的なPCのChrome環境において、p95で50ms以内に変換を完了すること。
  * ※リアルタイム追従における処理負荷を軽減するため、入力時は500msのdebounce処理を適用する。

### 7.2. セキュリティ・プライバシー
* アプリケーションのロード完了後、入力テキストおよび置換マップを含む外部通信を一切発生させない。
* CSPを設定して外部との不要な通信を制限し、サプライチェーン攻撃リスクを軽減する。
* すべての接続はHTTPSを強制する。

### 7.3. アクセシビリティ (A11y)
* **キーボード操作:** Tabキーでのフォーカス遷移、Enter/Spaceでの実行など、マウスなしでフル機能が操作可能であること。
* **スクリーンリーダー対応:** 適切な `aria-label` および `role="tablist"` などのARIA属性を適用すること。
* **状態の視覚表現:** コピー完了など、色だけに依存しないアイコン＋テキストの表示を行うこと。
* **コントラスト比:** WCAG 2.1 Level AA に準拠したコントラスト比（4.5:1以上）を確保すること。

### 7.4. 保守性
* サーバーレス・DBレスの静的配信とすることで、独自のバックエンドインフラ障害リスクを排除し、サーバーの保守運用負荷を最小化する。

### 7.5. 検証要件（テスト方法）
* アプリケーションの初回ロード完了後に入力・変換・コピー・インポート・エクスポートを操作し、ブラウザのデベロッパーツール（Networkタブ）等において追加の通信（HTTPリクエスト等）が発生しないことを試験・検証する。

## 8. 開発ロードマップ（1ヶ月・全4週）

* **Week 1：コアロジック実装**
  * プロジェクトセットアップ（Vite + React / Tailwind CSS）。
  * 固有タグ形式（`[CN_CATEGORY_0001]`）による単語置換・マップ管理（Mapオブジェクト）のJavaScriptロジック作成。
  * 主要な機密情報（APIKEY、IPV4、IPV6、EMAIL、PHONE）の正規表現判定ロジックの実装（重複・優先順位考慮）。
* **Week 2：UI/UX構築**
  * 画面レイアウト（ヘッダー、2タブ構造、左右2カラム、画面幅に応じたPC/スマホ表示制限）の構築。
  * カスタム単語追加（サイドバー連携 / PCのみ）UIおよび置換マップ管理UI（確認・個別削除機能）の実装。
  * 置換マップの一括クリア（確認ダイアログ付き）、エクスポート・インポート（PCのみ / JSONスキーマ検証付き）機能の実装。
  * コピー完了・失敗時のトースト通知の実装。
* **Week 3：例外処理・動作検証**
  * 表記揺れ吸収ロジックの追加（ASCII大文字小文字・空白許容）。
  * ブラウザのネットワークタブで通信（リクエスト）が発生しないことの完全検証。
  * CSPポリシーの設定。
* **Week 4：デプロイ＆マーケティング**
  * Cloudflare Pages へのデプロイ・ドメイン（`circle-note.com`）紐付け。
  * Qiita / Zenn での開発秘話記事執筆。
  * X（旧Twitter）での操作動画付きリリース告知投稿。
