# 実装フェーズ2：UI/UX構築 (Week 2)

本ドキュメントは、実装フェーズ2（React コンポーネント構築、アクセシビリティ (A11y) 対応、レスポンシブレイアウト、およびコンポーネントテストの設計と実装）におけるタスク詳細と手順を定義します。

---

## 1. 実施タスク & 手順

### 1.1. メインレイアウト & デザインシステム構築 (`src/App.tsx`, `src/App.css`)
1. **全体のレイアウト構築:**
   * ヘッダー（ロゴ、セキュリティステータスバッジ）およびコンテンツ領域の枠組みを作成。
   * Tailwind CSS を用いて Slate/Zinc 系のシックなダークテーマをベースにし、ボタンやバッジにエメラルドグリーン（`#10B981`）アクセントを適用。
   * トースト通知エリア（画面下部中央、3秒フェードアウト）およびモーダル表示用ポータルのコンテナを配置。
2. **レスポンシブ表示制御:**
   * 画面幅 768px（`md` ブレークポイント）を境界線とし、PC用（左右2カラム）とモバイル用（縦一列配置：入力 ➔ 出力 ➔ マップ/ステータス ➔ 共通クリア）を切り替え。
   * PC専用機能（カスタム登録パネル、インポート・エクスポートボタン）を `hidden md:block` で制御。

### 1.2. アクセシビリティ (A11y) に準拠したタブコンポーネント (`src/components/TabContainer.tsx`)
1. **WAI-ARIA 属性のバインド:**
   * `role="tablist"`, `role="tab"`, `role="tabpanel"` を適用。
   * 選択中のタブボタンに `aria-selected="true"`, `tabindex="0"`、非選択に `aria-selected="false"`, `tabindex="-1"` を付与。
2. **キーボード制御:**
   * 矢印キー（`←` / `→`）をイベントハンドラで検知し、フォーカスを隣のタブへ移動すると同時に活性タブを即座に切り替えるキーボードフォーカス移動ロジックを実装。

### 1.3. 仮名化タブ & 復元タブコンポーネントの構築 (`src/components/MaskTab.tsx`, `src/components/UnmaskTab.tsx`)
1. **ドラッグ選択と自動ロックUI (MaskTab):**
   * テキスト入力 `<textarea>` での `select` / `mouseup` イベントをハンドリングし、`selectionStart` と `selectionEnd` を用いて、`textarea.value.slice(textarea.selectionStart, textarea.selectionEnd)` で選択されたテキスト文字列を取得。
   * 空文字列の選択、およびドラッグの逆方向選択（選択の開始・終了のインデックス値の大小関係を `Math.min`/`Math.max` で吸収）を考慮して安全に取得する。
   * 選択テキストをカスタム単語追加の入力フィールドに自動転記（ロック）。他の場所をクリックしても、転記された文字がクリアされないロック機構を実装。
2. **コピー失敗時のフォールバック:**
   * Clipboard API が非対応または権限エラーで失敗した際、出力 `<textarea>` を全選択（`select()`）状態にしてフォーカスを当て、手動コピーを促すトーストを表示。
3. **個別削除と一時除外リスト管理:**
   * 置換マップ一覧カードの左側の `×` ボタン押下時に、該当項目を `substitutionMap` から削除し、同時に `ExcludeList` (React State) に登録。
   * 入力変更時に除外リストをクリアするライフサイクル管理（入力文字が変わった際に `ExcludeList` を空にする処理）を React の onChange イベントハンドラ内で実装する。
4. **Unmask 復元状況の表示 (UnmaskTab):**
   * 復元成功件数 (`restoreCount`) および、マップに登録がなく復元できなかった未復元タグ名の一覧（`unrestoredTags`）を画面上にリスト表示。

### 1.4. 共通操作 & モーダルダイアログの実装 (`src/components/CommonActions.tsx`)
1. **ResetButton:**
   * 共通操作エリアに配置し、全画面幅で表示。
   * 押下時に確認ダイアログ（「置換マップとテキストが完全に消去されます。よろしいですか？」）をポップアップし、承認後一括クリアしトーストを表示。
2. **MapTransferButtons (エクスポート・インポート / PC専用):**
   * エクスポートボタン押下時にセキュリティ警告を明示。
   * インポートファイル選択時に `mapFileService` を呼び出し、検証が成功した後に、タグ件数や重複マージ競合（自動リナンバリング等）の要約を含む「インポートプレビューダイアログ」を表示。ユーザー確定操作をもって一括更新を実行。キャンセル時は状態を変更しない。

## 2. コンポーネントテスト計画 (React Testing Library)

RTL を用いて各コンポーネント単体の挙動とアクセシビリティを検証します。

* **タブキーボード操作テスト:**
  * 活性タブにフォーカスがある状態で `→` 矢印キーを押下した際、活性タブが切り替わり、フォーカスが同期して移動すること。
* **コピー・フォールバックテスト:**
  * クリップボード書き込み失敗時に、出力テキストエリアが正しく全選択状態になること。
* **ダイアログ & フォーカストラップテスト:**
  * モーダルダイアログ（クリア確認、インポートプレビュー）の表示時に、フォーカスがモーダル内にトラップされ、スクリーンリーダーから背景コンテンツが隠れる（`aria-hidden`）こと。
* **トースト表示テスト:**
  * コピー成功、クリア完了等の操作時にトーストが自動で表示され、3秒後にフェードアウトすること。
* **一時除外リストライフサイクルテスト (RTL/移管項目):**
  * 個別削除した際に一時除外リストへ正しく追加され、その後入力テキストが変更された時点で除外リストが完全にクリアされること。
* **レスポンシブ境界表示テスト (RTL):**
  * RTL (jsdom) 環境ではCSSメディアクエリの表示切替を正確にテストできないため、レスポンシブ用のクラス（例: `hidden md:block` や `md:hidden` 等）が対象の要素に正しく付与されていることをアサーション検証する（768px未満の viewport での要素の物理的な非表示とレイアウト切替の検証は、Phase 3の Playwright による実ブラウザテストに委ねる）。
